# Capture checklist — hero video footage

Record once, re-cut forever. Put finished clips in `docs/hero-video/footage/` using the names below (or edit `timeline.toml` to match your filenames).

**Tools (suggested):** OBS, Windows Game Bar, macOS Screenshot→Record, or any 1080p60 capture. Prefer **16:9**, **constant frame rate**, no heavy compression artifacts on terminal text.

**Audio:** desk / boot clip must include the boot sound. Other clips may be silent; the assembler can drop audio on time-lapse segments.

---

## Before you roll

1. **Clean start practice GCU:** for a honest Xuss first-ship capture, `tig/xuss` `main` tip should be the product-only clean start (see silico `AGENTS.md` practice-GCU rules). Reset only with operator go.
2. **Quiet desktop:** hide unrelated windows, large fonts in terminal (14–18 pt), dark theme OK if contrast is high.
3. **Cursor:** slow deliberate moves on GitHub scroll and highlight; viewers cannot read a 4× mouse blur.
4. **Clock truth:** note wall-clock start when you paste the agent prompt (or when the session truly starts). Fill `session_start_sec` / `session_end_sec` in `timeline.toml` from that log so the burn-in clock matches real elapsed first-ship time.
5. **Surprising metal:** boot tone / LEDs — fine in the desk clip; do not startle someone off-camera without a heads-up.

## Mark human gates in the session tape

While recording `03-agent-session.mp4`, drop a **marker** (OBS chapter, spoken “gate”, or notepad timestamps) at:

| Marker | Why slow in edit |
|--------|------------------|
| Start gate (yes / adjust) | First human go |
| Plug USB / wait-device | Physical act |
| Confirm board | Identity |
| Confirm deploy | Scary write |
| Product-face observe | “Do you see/hear …?” |

In `timeline.toml`, cut those windows as separate `[[segments]]` with `speed = 1.0` (or `0.75`) and time-lapse the agent-only stretches with `speed = 20`–`60`.
