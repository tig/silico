# Onscreen capture with [tig/mcec](https://github.com/tig/mcec)

**Primary path for every desktop beat** in the silico × xuss hero: **MCEC drives the UI and records it**. No OBS / Game Bar for browser, terminal, agent TUI, or GitHub CI.

Pattern matches MCEC’s own hero and WinPrint’s:

| Project | Subject | Recipe |
|---------|---------|--------|
| [tig/mcec](https://github.com/tig/mcec) | MCEC Settings tour | [dev/hero-gif.md](https://github.com/tig/mcec/blob/develop/dev/hero-gif.md) |
| [tig/winprint](https://github.com/tig/winprint) | WinPrint GUI | [docs/hero-gif-win.md](https://github.com/tig/winprint/blob/develop/docs/hero-gif-win.md) |
| **tig/silico** (this file) | Browser + terminal + agent + CI | onscreen segments of [SCRIPT.md](SCRIPT.md) |

**Not MCEC:** desk / metal product-face clip (real camera + mic). Opening still and end card are generated by [build.py](build.py).

---

## Why MCEC here

- **Drive:** `launch`, `query`, `click`, `drag`, `send_command` (typed path through the real Windows UI).
- **Record:** agent tool `record` → animated **GIF** of a window or screen region (no external screen-recorder).
- **Reproduce:** a fresh agent with an MCP controller can re-run the playbook; tour logic lives in this doc, not a brittle committed macro.

Shared MCP envelope, targeting gotchas, and absolute-path rules: mcec [Agent Control](https://tig.github.io/mcec/agent_control.html) and [hero-gif.md](https://github.com/tig/mcec/blob/develop/dev/hero-gif.md). This page only adds **silico-specific** subjects and outputs.

## Limits you must plan around

MCEC `record` writes **GIF**, not MP4. Operator-clamped defaults (see mcec `AgentRecordMax*` settings):

| Knob | Default | Meaning for this hero |
|------|---------|------------------------|
| `AgentRecordMaxDurationMs` | 60000 | ~**60 s** per take unless you raise it on the **controller** |
| `AgentRecordMaxFrames` | 600 | Hard frame cap (at 5 fps ≈ 120 s) |
| `AgentRecordMaxWidth` | 1280 | Downscale width; fine for web hero |
| `AgentRecordMaxFps` | 30 | Cap; use **4–8 fps** for size |

**Implication:** do **not** try one hour-long first-ship as a single `record`. Split onscreen work into **short takes** (table below). The final [timeline.toml](timeline.toml) stitches them and applies time-lapse / slow-mo; the burn-in clock still tracks real session time via `session_*_sec`.

To allow longer agent-stage takes, raise `AgentRecordMaxDurationMs` / `AgentRecordMaxFrames` on the **throwaway controller** only (not your installed Program Files gates). Still prefer multiple stage clips for re-cuts.

## Setup: MCEC controller

Same bootstrap as other Kindel heroes — **from a clone of tig/mcec**, not from Program Files:

```powershell
# mcec repo root
pwsh -NoProfile -File scripts/Generate-HeroGif.ps1
# → HERO_MCP_URL=http://127.0.0.1:<port>/mcp
```

Register that URL with your agent MCP client, or POST JSON-RPC as in mcec’s hero-gif appendix.

**Controller config for silico (marketing subject, not MCEC dogfood):**

| Setting | Value | Why |
|---------|--------|-----|
| Command overlay | **OFF** | Same as WinPrint hero: clean product path, no burnt-orange narration |
| `record` / `query` / `click` / `launch` / `send_command` / `displays` / `windows` / `drag` | enabled | Drive + record |
| `AllowSessionProvisioning` | optional | Only if you provision throwaway subjects |

Edit the throwaway controller under `%TEMP%\mcec-hero-controller-*` (`mcec.settings` / `mcec.commands`), then relaunch that copy’s `mcec.exe` if overlay is read only at startup.

Tear down when done:

```powershell
pwsh -NoProfile -File scripts/Generate-HeroGif.ps1 -Stop
```

**Operator machine:** unlocked interactive Windows session (injected input), MCEC recent enough for `record` + tools you use, browser + terminal + agent TUI installed, `gh`/git auth already done so the capture does not leak tokens.

## Safety (do not skip)

- Agent surface is **powerful**; emergency stop default **`Ctrl+Alt+Shift+S`** (physical keys only).
- Prefer the **disposable controller** from `Generate-HeroGif.ps1`, not enabling gates on the Program Files install.
- `record` captures the **whole duration** of the region — no credentials, secrets, or private chats in frame.
- Every tool call is `AGENT-AUDIT:`-logged; that is intentional.

Full model: [Agent Safety](https://tig.github.io/mcec/safety-emergency-stop-and-provisioning.html).

## Playbook (agent drives via MCEC tools)

Coordinates are absolute screen pixels; **integers only**. Unwrap the double MCP envelope (`ok` / `result` / `error`) as in mcec hero-gif. Absolute paths for `record` `file=` (controller cwd is the temp copy).

### Shared open for every take

1. `displays` → primary `SX, SY, SW, SH`.
2. Win+D: `send_command` `shiftdown:lwin` → `d` → `shiftup:lwin` (clear backdrop).
3. Launch or focus the **subject** window (browser, terminal, agent) with `launch` / `windows` / `query`.
4. `query` or `windows` → subject bounds `WX, WY, WW, WH`.
5. `record start` on a region that includes the subject (and **not** unrelated private windows):

   ```text
   record {
     action: "start",
     x: WX, y: WY, width: WW, height: WH,   # or a band that fits the story
     fps: 6,
     maxWidth: 1280,
     file: "<ABS>/silico/docs/hero-video/footage/<name>.gif"   # optional until stop
   }
   ```

   Or omit `file` until `record stop` and pass absolute `file` there.

6. Drive the beat (below). Dwell so text is readable (0.5–1.5 s on key frames).
7. `record stop` with absolute `file` under `docs/hero-video/footage/`.
8. Spot-check the GIF; re-take rather than “fix in post.”

### Beat A — GitHub silico Getting Started (`01-…`)

1. `launch` browser (or focus existing) → navigate to `https://github.com/tig/silico` (address bar via `click` + `chars:` + enter).
2. Scroll until **Getting Started** / agent start prompt is in view (`send_command` page-down / wheel, or click TOC).
3. Highlight the prompt block (browser find for a distinctive line of the prompt, or slow drag-select).
4. Hold 2–3 s on the highlighted prompt.
5. Stop record → `footage/01-gh-silico-getting-started.gif`.

### Beat B — Terminal clone + agent + paste (`02-…`)

1. Launch terminal (Windows Terminal / pwsh). Large font.
2. Type or paste, **readable** pacing:

   ```text
   git clone https://github.com/tig/xuss
   cd xuss
   grok
   ```

3. Paste the Silico start prompt into the agent:

   ```text
   Read https://github.com/tig/silico's AGENTS.md. Follow the guidance there exactly. Stay in this product checkout.
   ```

4. Stop once the agent is clearly running (before the long first-ship monologue) → `footage/02-terminal-clone-and-prompt.gif`.

### Beat C — Welcome only (`03a-…`)

1. Focus the agent window once Stage **0a** orientation (`silico welcome` skeleton) is on screen.
2. Record a short window where the welcome is fully readable; do not race.
3. Stop → `footage/03a-welcome.gif`.  
   In [timeline.toml](timeline.toml), play this segment with `speed < 1` so viewers get ~2–3 s of readable time.

### Beat D — First-ship body, segmented (`03b…`, `03c…`)

Drive (or let the product agent run while MCEC **records**) host stages and gates. **Start/stop `record` at natural boundaries:**

| Take | Content | Timeline use |
|------|---------|--------------|
| `03b-host-stages.gif` | Tools install, workspace lock, scaffold, host gate green | high `speed` time-lapse |
| `03c-human-gates.gif` | start-gate, confirm-board, confirm-deploy, product-face ask | `speed = 1` |
| more `03d-…` as needed | metal inspect/deploy UI if on-screen | mix |

Log wall-clock offsets in [record.md](record.md) so `session_*_sec` stay honest.

If the product agent is a **different** process from the MCEC-driving agent: MCEC still records the product agent’s window; the operator (or a second agent connected to MCEC) only needs to start/stop `record` and optionally slow-scroll. Driving the product agent’s *judgments* is still the human / product session — MCEC does not replace Bedside gates.

### Beat E — CI green (`05-…`)

1. Browser → `https://github.com/tig/xuss/actions` (or PR checks).
2. Hold on a green run for main / the ship branch.
3. Stop → `footage/05-xuss-ci-green.gif`.

### Desk (not MCEC)

Phone or camera for boot sound + product face → `footage/04-desk-xuss-boot-demo.mp4`. Keep audio.

## Anti-patterns

| Don’t | Do |
|-------|-----|
| OBS for browser/terminal “because GIF is limited” | Multiple MCEC takes + timeline speed |
| Record from Program Files MCEC with agent gates left on | Disposable controller (`Generate-HeroGif.ps1`) |
| Overlay ON for silico marketing cut | Overlay OFF (product is silico, not MCEC) |
| Relative `file` path for `record stop` | Absolute path under this repo’s `footage/` |
| One multi-hour `record` | Segmented takes; optional higher controller max duration |
| Past-HEAD salvage “last session’s screen” | Fresh clean-start xuss first ship when claiming honesty |
